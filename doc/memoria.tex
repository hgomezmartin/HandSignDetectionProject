% Abstract en castellano
\renewcommand*\abstractname{Resumen}
\begin{abstract}
Este proyecto presenta el desarrollo de un sistema de reconocimiento de lenguaje de signos Americano (ASL) que se basa en visión por computador y aprendizaje profundo, desplegado en una Raspberry Pi 5. Para llevarlo a cabo, combinamos la implementación de la detección de manos (\texttt{cvzone}) y la clasificación de gestos con una red neuronal convolucional (CNN) entrenada con \texttt{TensorFlow/Keras} sobre un dataset propio de 26 clases con 1000 imágenes cada una. 

El modelo se prepara para su ejecución embebida con \texttt{TensorFlow Lite} y se integra en una aplicación \textit{Streamlit} que permite tanto la clasificación en tiempo real, la clasificación con una imagen estática y además implementa una interfaz para poder re-entrenar el modelo con nuevos datos.
\end{abstract}

\renewcommand*\abstractname{Descriptores}
\begin{abstract}
ASL, reconocimiento de gestos, Raspberry Pi, TensorFlow Lite, Keras, aplicación web, Redes Neuronales Convolucionales
\end{abstract}

% Abstract en inglés
\renewcommand*\abstractname{Abstract}
\begin{abstract}
This project presents the development of an American Sign Lenguage (ASL) recognition system based on computer vision and deep learning, deployed in a Raspberry Pi 5. To achieve this, we combine hand detection using \texttt{cvzone} and gesture classification with a convolutional neural network (CNN) trained with \texttt{TensorFlow/Keras} on a personal dataset of 26 classes with 1000 images each.

The model is prepared for embedded execution with \texttt{tensorFlow Lite} and integrated into a \texttt{Streamlit} application that supports real-time classification, single-image classification, and provides an interface for retraining the model with new data.
\end{abstract}

\renewcommand*\abstractname{Keywords}
\begin{abstract}
ASL, gesture recognition, Raspberry Pi, TensorFlow Lite, Keras, web application, convolutional neural networks
\end{abstract}
